# MacWall

MacWall is a network monitor and firewall for macOS. It shows every connection your Mac makes: which app opened it, where it goes, which country the server is in, and how much data went out. You can block or allow connections, or have MacWall ask you about them.

- Live log of TCP and UDP connections, with the process tree behind each one
- Block, Allow and Ask rules, written in FQL, a small flow query language
- Country lookup using a GeoIP database built into the app, plus a world map
- A built-in MCP server, so AI agents can query your network activity
- Command-line interface
- Private by design: logs and rules stay on your Mac, with no account, analytics or tracking

Website: [macwall.net](https://macwall.net)

## Source code

MacWall is under active development and its source is closed for now. The code will be published in this repository under an open-source license once a stable version is released.
